================================================================================
TO RUN ON YOUR LOCAL MACHINE
================================================================================

1. Install Python dependencies:
   cd ~/documents/selznick_3/autoresearch
   pip install -r requirements.txt

2. Set up API keys:
   cp .env.example .env
   # Edit .env file and add:
   #   ANTHROPIC_API_KEY=your_key_here
   # OR
   #   OPENAI_API_KEY=your_key_here

3. Ingest your PDFs (one-time, ~2-3 minutes):
   python main.py ingest-pdfs

4. Build benchmark with labels (one-time, ~1 minute):
   python main.py build-benchmark --labels-csv data/benchmark/master_pilots_labels.csv

5. Run baseline evaluation (~4-6 hours for 900+ scripts):
   python main.py run-eval

6. View results:
   python main.py show-results
